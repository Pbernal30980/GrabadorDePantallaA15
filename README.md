# Grabador de pantalla (sin anuncios)

App propia para grabar la pantalla del Samsung Galaxy A15 (sirve para cualquier Android 10 o superior).

## ⬇️ Descargar

**[Descargar Grabador.apk](https://github.com/Pbernal30980/GrabadorDePantallaA15/raw/main/apk/Grabador.apk)**

## Qué hace
- Graba la pantalla en 1080p, 720p o 480p (baja sola si el teléfono no aguanta la calidad elegida).
- Sonido: sin sonido, sonido interno, micrófono, o interno + micrófono.
- Pausar / reanudar / detener desde la notificación o desde la app.
- Botón en el panel rápido ("Grabar pantalla").
- Los videos quedan en la Galería, carpeta `Movies/Grabador`.

## Cómo se compila
GitHub Actions compila el proyecto en cada cambio (`.github/workflows/build.yml`).
